Ryo · COMBO / CLASH / GUARD sound audition

Tap ▶ to play (tap again to stop). Read from the game source v4.30.1 (src/ui.js). Nothing here is synthesized or AI-made: every file is a real recording.

Ryo and Aoi share these today. combo2, combo3, clash, guard and pl_guard are not per-character (only the attack and charge card sounds are, pl_atk_ryo / pl_atk_aoi). To change Ryo only, I'd add Ryo-only keys (for example clash_ryo) and leave Aoi on the current files. Aoi's sounds are a separate pass, as you asked.
Timing: the combo punches on screen are fixed at 0.16 s apart (double) and 0.13 s (triple). C3 and C4 already match. The others would be re-spaced to those gaps when they go in, the way the current ones were built.

pl_guard.mp3 GUARD
Card-type sound when a Guard card is played (both fighters). Measured: it is the same recording as guard (99.8% match, only re-encoded), so today a Guard card plays this, then "GUARD +n" plays the same thud again.
